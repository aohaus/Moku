Mokuball · Art Direction v1

Solid-state era,
1980s playfield parts

Every part below is drawn with the same canvas code that will run in the game — this sheet is the implementation, not a mockup of it. Geometry (where parts sit) stays exactly as tested; only material, lighting and form change. Approve or redline the parts, then I re-skin the table.

01 / Palette

The accent pair #B98CFF / #4B2E7A is locked by the series spec. Everything else is support: four insert-lamp colours (the 80s cabinet used coloured translucent inserts, not neon outlines) plus chrome, wood and the playfield ground.

02 / Materials

The current build renders every object as a glowing outline, so wood, steel, plastic and rubber all read identically. These are the five surfaces that need to look different from each other.

03 / Playfield parts

Each part is shown in its resting state and its active state, since the active state is what sells the machine as electro-mechanical. Numbers match the reference diagram.

04 / Cabinet & score display

The single biggest gain: the game currently floats a playfield in space. A real machine is a backbox with a score display, a playfield, and an apron across the bottom. This frame does most of the work of reading as “an actual machine”.
